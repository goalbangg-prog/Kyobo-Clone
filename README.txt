============================================================
v13 - 직접 큐레이션 방식
============================================================

[가장 중요한 변경]

앞으로 메인페이지에 표시할 책은

    js/curated-books.js

파일 하나에서 관리합니다.


예:

best: [
  "정의란 무엇인가",
  "모순",
  "소년이 온다"
]

배열의 제목을 바꾸면,
Kakao Book API가 해당 제목의 책을 찾아
표지 / 저자 / 가격 / ISBN을 자동으로 가져옵니다.


[구조]

curated-books.js
        ↓
main.js
        ↓
books.js
        ↓
api.js
        ↓
Kakao Book API


[장점]

1. API는 그대로 사용
2. 원하는 책만 직접 선택 가능
3. HTML에 책 정보를 하드코딩할 필요 없음
4. 베스트 순서도 배열 순서대로 제어 가능
5. Kakao 검색 결과 중 표지가 있는 책을 우선 선택
6. AI 추천 Picks 전용 레이아웃 적용


[주의]

같은 제목의 책이 여러 판본으로 존재할 경우
원하지 않는 판본이 나올 수 있습니다.

그럴 때는 제목을 더 구체적으로 적으세요.

예:

"정의란 무엇인가"

→

"정의란 무엇인가 마이클 샌델"

[v16 - 5권 강제 유지 구조]

이번 버전부터는 Kakao API가 특정 책을 못 찾더라도
그 책의 카드 자체를 제거하지 않습니다.

즉 curated-books.js에 5개를 넣으면
화면에도 반드시 5개의 카드가 유지됩니다.

특히 '토마토 컬러맨'처럼 Kakao Book API에서 검색이 잘 안 되는 책은
직접 표지 이미지를 사용할 수 있습니다.

1. 표지 파일을 다음 위치에 넣습니다.

   img/book/tomato-colorman.jpg

2. curated-books.js에서 다음처럼 작성합니다.

{
  query: "토마토 컬러맨 차정은",
  title: "토마토 컬러맨(스페셜 에디션)",
  authors: ["차정은"],
  thumbnail: "img/book/tomato-colorman.jpg"
}

이 방식은 앞으로 사용자가 직접 책을 큐레이션할 때도 활용할 수 있습니다.


============================================================
v17 - 최종 기능 1차 완성
============================================================

1. 로고 클릭
   - 메인 로고: index.html로 이동
   - 서브페이지 로고도 index.html로 이동

2. 모든 API 도서 카드
   - sub.html?isbn=ISBN 형식으로 상세페이지 이동

3. 실시간 통합검색
   - 검색어 입력 후 250ms 뒤 Kakao Book API 호출
   - 왼쪽: 관련 도서 최대 4권
   - 마우스를 올리면 오른쪽 상세도서 변경
   - 오른쪽: 표지 / 제목 / 저자 / 출판사 / 가격 / 설명
   - 하단: 관련 인물(저자) 표시
   - 이벤트: 데모 영역

4. 검색결과 클릭
   - 해당 책의 ISBN을 sub.html로 전달

5. Enter
   - 검색결과 첫 번째 책의 상세페이지로 이동

6. 검색 패널
   - 바깥 클릭 또는 닫기 버튼으로 닫힘

※ Kakao Book API는 교보문고 이벤트/인물 전용 API가 아니므로
   '인물'은 검색된 도서의 저자를 활용했고
   '이벤트'는 UI 데모 형태로 구현했습니다.
